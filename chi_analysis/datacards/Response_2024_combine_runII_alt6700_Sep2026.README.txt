            5400-6000, 6000-7000, 7000-13000                       (9 channels)
  alt6700 : 1900-2400, ..., 5400-6000, 6000-6700, 6700-7500, 7500-13000
                                                                    (10 channels)

  chi binning: 12 bins [1..10,12,14,16] below 7 TeV, 5 bins [1,3,6,9,12,16] for
  channels whose lower edge is >= 7000.  So in alt6700 only 7500-13000 is coarse;
  6700-7500 keeps 12 chi bins.  (Can switch to coarse-from-6700 on request.)
  "runII" means the Run 2 TOP END; the floor stays at 1900 (the Run 2 file went
  down to 1200 -- that would need the skimmed low-HT samples).

VALIDATION
  Both files are merged from ONE migration built on a 100 GeV mass grid
  (1900-10000 + 10000-13000) x fine chi.  Regenerating the previous binning
  this way reproduces Response_2024_combine_Sep2026.root EXACTLY for all RECO
  templates (13497 bins, zero difference); SMR templates agree within smearing
  RNG (pull RMS 0.95).  Any further binning with edges on the 100 GeV grid can
  be produced in seconds -- just send the edges.
